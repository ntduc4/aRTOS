# Code of Conduct

Be respectful, constructive, and patient. Discuss ideas and code rather than
attacking people. Harassment, discrimination, threats, sexualized content,
doxxing, and deliberate disruption are not acceptable.

These expectations apply to repository issues, pull requests, reviews, and
other project spaces. Maintainers may edit, hide, or remove content and may
temporarily or permanently restrict participation when necessary.

If you experience or observe unacceptable behavior, report it privately to the
maintainer through the contact options on their GitHub profile. Do not post
sensitive personal information in a public issue. Reports will be reviewed as
time permits and handled as privately as reasonably possible.
