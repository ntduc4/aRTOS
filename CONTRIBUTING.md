# Contributing

Thanks for your interest in aRTOS. This is a completed educational project,
maintained on a best-effort basis. Issues and pull requests may not receive an
immediate response, and feature requests may be declined to keep the project
small.

## Issues

- Search existing issues before opening a new one.
- Include the board, environment, toolchain, expected result, actual result,
  and minimal reproduction steps for bugs.
- Open an issue before investing in a large change or a new architecture port.
- Do not use public issues to disclose security-sensitive information.

## Pull Requests

- Keep each change focused and explain why it is needed.
- Follow the existing code style and preserve the static, no-allocation design.
- Update documentation and tests when behavior changes.
- Build the affected PlatformIO environments and report the commands run.
- Be willing to revise the change after review.

By contributing, you agree that your contribution is licensed under the
repository's MIT License.
